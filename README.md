# JourneyTen

## Travel Planner & Trip Optimizaiton App
This is a full-stack ASP.NET Core MVC application for planning trips, building itineraries, tracking expenses, and generating travel insights.

### Overview 
This application will allow users to create and manage trips. Trips will include destinations, travel (flights/drive time), accomodation (hotels/airbnbs), and activities. This application will act as an all inclusive itinerary for trips. Users will be able to view maps and monitor weather forecasts.

- Add & categorize travel
- Add & detail accomodation

- Visual reports (maybe using Chart.js)
